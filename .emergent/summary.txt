<product_requirements>
Ara is a full-stack, gamified video streaming mobile app for Gen Z (18-34) on iOS/Android. Key features include a 5-tab bottom navigation (Home, Live, Explore, Profile, Creator Dashboard), preloaded 720p video streaming with watch-time tracking, and HLS/RTMP-based live streaming for creators and viewers. A token system rewards +1 token/minute watched and +2 tokens/Color Pulse choice. The Color Pulse feature prompts users every 9 minutes to pick 3 random colors, tracks choices, and assigns neurodiversity classes. It now includes a mandatory baseline assessment at the start of every viewing experience, asking about mood, weather, and favorite memory. Advertisements are integrated as rotating bottom and side bars. A Creator Dashboard shows real-time stats, and a basic leaderboard is in the Profile tab. The UI features a neon gradient theme. Recent additions include full-screen video playback, a Go Live feature for creators (currently simulated), YouTube-style comments for preloaded videos, and Twitch-style live chat for live streams. Google Drive video integration was done for quality assessment.
</product_requirements>
